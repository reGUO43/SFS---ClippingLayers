# SFS---ClippingLayers
мод для Spaceflight Simulator.
**Clipping Layers** — мод для **Spaceflight Simulator 1.6**, позволяющий управлять перекрытием деталей ракеты.

Назначайте каждой детали слой от **−10 до +10**: чем выше значение, тем ближе деталь к переднему плану. Создавайте аккуратные обтекатели, декоративные элементы и сложные конструкции с наложением деталей.

- Выбор слоя в небольшом окне прямо в редакторе.
- Быстрое изменение слоя кнопками «Выше» и «Ниже».
- Сохранение слоёв в чертежах и перенос в полёт.
- Поддержка копирования деталей и Undo/Redo.
- Интерфейс на встроенной библиотеке `SFS.UI.ModGUI`, без зависимости от UITools.

Написан на C# для Unity с использованием Harmony.
